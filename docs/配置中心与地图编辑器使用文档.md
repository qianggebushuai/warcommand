# WarCommander 使用文档：配置中心 & 地图布局编辑器

> 适用于 2026-11 版本。两件工具均为独立 pygame 窗口程序，在项目根目录启动，互不影响游戏本体运行。

---

## 一、AC130 炮弹数值在哪改

AC130 的所有数值都已接入 **配置中心**（`config/units.json`），改完**保存并重启游戏**生效。
代码里 `core/settings.py` 只保留默认值——`units.json` 中的同名键会在游戏启动时自动覆盖它们。

### 1.1 AC130 数值总表（配置中心“伤害”页与“属性”页）

| 数值 | 默认 | 含义 | 改哪里 |
|---|---|---|---|
| `DMG_AC130` | 15 | 机炮单发伤害（小溅射 AOE 40） | 配置中心 → 伤害 页 |
| `DMG_AC130_HOWITZER` | 200 | 榴弹炮单发伤害（大面积溅射） | 配置中心 → 伤害 页 |
| `AC130_HOWITZER_AOE` | 110 | 榴弹炮溅射半径（px），≥80 时落点播放大爆炸特效 | 配置中心 → 伤害 页 |
| `AC130_HOWITZER_COOLDOWN` | 240 | 榴弹炮发射间隔（帧，60帧=1秒） | 配置中心 → 伤害 页 |
| `AC130_ATTACK_RADIUS` | 350 | 默认攻击半径；盘旋半径 = 攻击半径 × 2 | 配置中心 → 伤害 页 |
| `AC130_DURATION` | 900 | 空中盘旋总时长（帧），到时离场 | 配置中心 → 伤害 页 |
| `AC130_STATS`（hp/speed/range） | 800 / 2 / 0 | 血量 / 巡航速度 / 攻击射程占位 | 配置中心 → 属性 页 |
| `AC130_COST` | 800 | 生产造价 | 配置中心 → 造价 页 |
| `AC130`（build_time） | 5 | 生产所需冷却档位 | 配置中心 → 建造时间(帧) 页 |

### 1.2 两类“攻击半径”的区别（容易混淆）

- **配置中心里的 `AC130_ATTACK_RADIUS`**：全局默认值。地图编辑器新放置 AC130 时用它作为初始值。
- **地图编辑器里逐实例调整的攻击半径**：选中某个已放置的 AC130 后按 `+` / `-` 修改，随该地图 JSON 保存，只影响这一台炮艇（盘旋半径随之 = 2×攻击半径联动）。

### 1.3 直接改文件的方式（不推荐，但可用）

- `config/units.json`：`damage` 分区加入上表键值（推荐，配置中心可视化）。
- `core/settings.py` L79-85：默认值；只在没有同名 `units.json` 键时生效。

## 二、配置中心（config_center.py）使用文档

### 2.1 启动

```powershell
python config_center.py            # 编辑默认的 config/units.json
python config_center.py 某文件.json  # 编辑指定的配置文件
```

窗口 1200×720，编辑对象是 `config/units.json` —— 游戏**启动时**读取并覆盖内置数值。

### 2.2 界面布局

- **顶部标签条**：7 个分区标签。标签太多放不下时，标签条自身有**横向滚动条**（拖动滑块，或把鼠标悬停在标签条上滚动滚轮）。

  | 分区 | 内容 |
  |---|---|
  | 造价 | 每个单位/建筑的生产花费（单列“数值”） |
  | 属性 | 单位三围：**血量 / 速度 / 射程 / 采矿** 四列 |
  | 伤害 | 各类武器伤害值及武器参数（AC130 炮弹数值都在这里） |
  | 建造时间(帧) | 生产冷却档位 |
  | 建筑数值 | 建筑类数值 |
  | 电脑AI | AI 行为参数 |
  | 护甲 | 类名 → 护甲值表（整体生效，减算伤害） |

- **中部列表**：当前分区的全部条目。属性页四列很宽，列表底部有**横向滚动条**。
- **底部表单**：键名输入框 + 数值输入框（属性页为 4 个数值框）+ 按钮区。

### 2.3 修改一个数值（标准流程）

1. 点顶部标签切换到目标分区；
2. 在列表中**点选一行**（高亮），下方输入框自动载入该条目；
3. 在输入框中修改数值（属性页留空的列 = 保留原值）；
4. 点 **“应用修改”**（仅写入内存，状态栏提示成功）；
5. 点 **“保存”** 写回 `config/units.json`；
6. **重启游戏**生效（游戏只在启动时读一次配置）。

### 2.4 其余操作

| 按钮/操作 | 说明 |
|---|---|
| 添加新条目 | 键名框 + 数值框都填好后点它；键名须为 `字母/数字/下划线` 且不以数字开头 |
| 删除选中 | 删除列表中选中的条目；**需连点两次确认** |
| 重新加载 | 丢弃未保存的修改，从磁盘重读；**需连点两次确认** |
| 退出 | 有未保存修改时也**需连点两次确认** |
| 保存 | 写回 JSON 并自动留一份 `.bak` 备份 |

### 2.5 JSON 结构对照（手工编辑时可参考）

```jsonc
{
  "costs":  { "AC130_COST": 800, ... },                 // 造价页
  "stats":  { "AC130_STATS": {"hp":800,"speed":2,"range":0,
                              "mine":100}, ... },       // 属性页；mine=矿车满载量(可省)
  "damage": { "DMG_AC130": 15, "AC130_HOWITZER_AOE": 110, ... },
  "build_time": { "AC130": 5, ... },
  "buildings": { ... },
  "ai":     { ... },
  "armor":  { "类名": 护甲值, ... }
}
```

注意：

- `stats` 页的 `hp/speed/range` 对应游戏内 `[射程, 速度, 血量]` 列表约定，由程序自动换算，不要在 JSON 里写列表形式；
- `stats.HARVESTER_STATS.mine` 会覆盖全局采矿量 `HARVEST_AMOUNT`；
- `armor` 分区整体注入为 `UNIT_ARMOR` 字典，键是实体类名（如 `"M1A2": 30`）。

## 三、地图布局编辑器（map_layout_editor.py）使用文档

### 3.1 启动与地图切换

```powershell
python map_layout_editor.py            # 打开第一张地图
python map_layout_editor.py PARISMAP   # 直接打开指定地图
```

- `←` / `→` 或 `F1`–`F9`：切换地图（共 9 张：Wilderness、StormCoast、FrozenArchipelago、DragonValley、Crossfire、BroadcastCenter、Verdun、PARIS、BERING）。
- 保存位置：`config/map_layouts/<地图类名>.json`。运行游戏加载该地图时由 `apply_layout_override()` 自动读取生成，**无需其他配置**。

### 3.2 视图与面板

| 操作 | 效果 |
|---|---|
| 滚轮 | 以鼠标为中心缩放画布 |
| 中键拖拽 / `WASD` | 平移视角 |
| `Tab` 或面板右缘拉手 | 收起/展开左侧面板（面板挡住地形时收起） |
| 面板上滚动滚轮 | 滚动面板列表（内容超出屏幕时右缘出现滚动条） |

### 3.3 面板工具清单（从上到下）

1. **出生点**：列出所有出生点；左键点选后拖动移动；`[+]` / `[-]` 增减出生点数量（2–4 个）。
2. **中立建筑**：油井、特斯拉塔、摩天楼、民居、教堂、木筋房、钟楼、风车、通讯站、EMP 发生器、古庙、灯塔、堡垒、**桥**、工厂、电厂、雷达站、机场、研究中心、科技中心、防空炮塔、岸防炮等。点选后左键在画布上放置。
3. **矿脉**（OrePatch）：放置后可直接**拖动**调整位置。
4. **特殊单位**（连点 2 次：第一点=刷新点，第二点=目标点）：
   - **Train** 列车（沿铁路巡逻）
   - **Battleship** 战列舰（水上巡逻）
   - **AC130** 空中炮艇：中立敌对盘旋炮艇，见 3.5
5. **道路**：两点成路（起点→终点），面板可循环切换宽度档位（默认 64px）。
6. **地形多边形**：`water` 水域 / `land` 陆地 / `slope` 斜坡 / `cliff` 悬崖（仅空中单位可通行）。
   - 色预设：按当前绘制/选中的类型显示对应色板，点色块换色；
   - 透明度：`-` / `+` 按钮 10 档调节；
   - 波纹开关：选中水域多边形时出现，控制该水域是否渲染波纹特效。

### 3.4 通用编辑操作

| 操作 | 说明 |
|---|---|
| 左键 | 放置选中内容 / 移动选中的出生点、矿脉 |
| 右键 | 取消当前两点放置；或按 `建筑 > 多边形 > 道路` 优先级删除命中物（桥/特殊单位标记也可右键删除） |
| `Delete` | 同右键删除（非地形绘制模式下） |
| 空手（面板第一个）+ 左键 | 点选水域/地形多边形 → 面板出现颜色/透明度/波纹编辑 |
| `S` | 保存到该地图的布局 JSON |
| `L` | 丢弃修改并从 JSON 重载 |
| `ESC` | 退出（有未保存修改会提示） |

每一步操作顶部都有**状态栏提示**（flash 文字），照着提示点即可。

### 3.5 AC130 空中炮艇（特殊流程）

1. 面板点 **特殊单位 → AC130**；
2. **第一击**：放下刷新点（进场点）；**第二击**：放下目标点（盘旋中心）——两点的连线即进场方向；
3. 画布上会显示**攻击半径圈**（橙色）；
4. **切换到空手**（面板第一项），左键点 AC130 的标记 → 选中（半径圈变金色加粗，同时显示 0.5 半径内圈）；
5. 按 `+` / `=` / 小键盘`+`：攻击半径 +50；按 `-` / 小键盘`-`：−50。范围钳制在 **100–2000**；
   - 盘旋半径 = 攻击半径 × 2 自动联动；
   - 状态栏同步显示“AC130 攻击半径 → N（盘旋半径 2N）”；
6. `S` 保存。JSON 中该实例带 `"attack_radius"` 字段：
   ```jsonc
   "special_units": [
     { "type": "AC130", "spawn": [3200,3400], "target": [3200,3000],
       "attack_radius": 500 }
   ]
   ```
7. 游戏内：炮艇为**中立敌对单位**，围绕目标点盘旋并向攻击半径内**随机落点**开火（机炮连发 + 榴弹炮缓发），可被击落，死后按 `respawn_frames`（默认全局值）计时重生。

### 3.6 桥（两点放置，长度可定）

1. 面板选 **Bridge**，`R` 切换横/竖方向；
2. 左键定**起点**，再左键定**终点**（两点距离即桥长，自动生成对应碰撞箱，可跨水）；
3. 右键点桥删除。断桥样式、桥下 naval 通行规则由游戏运行时处理。

### 3.7 地形多边形绘制流程

1. 面板点 `water` / `land` / `slope` / `cliff` 之一进入绘制模式；
2. 左键依次加点；`Backspace` 撤销上一个点；`Enter` 闭合（至少 3 个顶点）；右键 / `Esc` 取消；
3. 空手状态下左键点已有多边形可选中：换颜色（色预设）、调透明度、水域可开关波纹；
4. `Del` / 右键删除选中的多边形（右键时建筑优先于多边形）。

### 3.8 布局 JSON 顶层结构（手工检查用）

```jsonc
{
  "bases":  [{"x":..,"y":..}, ...],          // 出生点
  "neutral": [...],                          // 中立建筑（含桥的 orientation/length）
  "ore":     [{"x":..,"y":..,"amount":..}],  // 布局矿脉（存在即替换随机矿脉）
  "terrain": [{"type":"water","points":[[..]],"color":[r,g,b],
               "alpha":150,"waves":true}, ...],
  "special_units": [ ... ],                  // Train/Battleship/AC130
  "roads":   [{"start":[..],"end":[..],"width":64}, ...]
}
```

## 四、常见问题

- **改了数值游戏里没变？** 两处原因：① 配置中心只点了“应用修改”没点“保存”；② 保存后没重启游戏（配置只在启动时读取）。
- **配置中心列表太宽/标签显示不全？** 属性页用列表下方横向滚动条；标签条悬停滚轮或拖顶部滑块。
- **AC130 想每台不同半径？** 在地图编辑器里逐台选中调整（见 3.5）；配置中心只改全局默认。
- **编辑器放的东西游戏里没有？** 确认 `S` 保存成功（状态栏提示 + `config/map_layouts/` 下 JSON 更新时间），且加载的是同一张地图。
