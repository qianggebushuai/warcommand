# 游玩策略手册（策略文案库 · AI 生成 JSON 指令时遵循的打法）

## 总原则

1. **经济优先**：先保障矿车采矿与油井占领，再扩军。
2. **一次只做一件事**：每轮扫描先完成当前最紧迫目标（补矿车 > 防守 > 进攻）。
3. **宁稳勿贪**：拿不准就 `wait`，不要乱点；错误的移动比等待损失大。

## 开局流程（前几分钟）

1. 打开基地生产栏 → 造**电厂**（冷却完放在基地附近空地）；
2. 造**矿车**（有工厂后）或按当前冷却栏可选项补经济；
3. 出 1–2 个矿车后补**工厂** → 持续生产采矿；
4. 放置第一个**矿车**后，派 1 个快单位侦查地图中央与油井位置。

## 中期

- **占油井/通讯站**：派步战车或快单位占领最近的油井，回资金滚雪球；
- **造防空**：发现对手有机场/直升机后，在基地与矿区各放一座**防空炮塔**；
- **扩军比例**：矿车 2–4 辆，坦克为主力（4–8 辆），保留 1–2 步战车侦查；
- **编队**：主力部队集中放置在基地到前线之间，不要散开。

## 进攻

- 集中 6+ 主战坦克再出击，目标选择顺序：**矿车 > 油井 > 电厂 > 工厂 > 基地**；
- 攻城前先清掉路过的防空炮塔（若有空中部队）；
- 打不过立刻右键把残血单位拉回基地方向，避免白给；
- 桥口/悬崖口是必经之路，把部队摆在出口侧防守，敌人会排队送死。

## 防守

- 小地图看到红点逼近 → 选中部队右键点击敌人方向拦截；
- 空袭来临（敌机/AC130）→ 部队散开，靠防空炮塔输出；
- 基地残血 → 优先回防，经济可以死，基地不能死。

## AC130 使用时机

- 敌方部队在**开阔地聚集**（无我方部队混战）时召唤，指向敌群中心；
- 召唤后我方部队撤出其攻击半径（随机落点不分敌我）；
- 配合进攻：先用 AC130 砸一轮，再推进收残。

## 常见操作映射（截图 → 指令）

| 意图 | 指令序列 |
|---|---|
| 选择单位 | mouse_click 单位坐标（左键） |
| 框选部队 | mouse_drag 从 A 到 B（左键） |
| 移动/攻击 | 先选择，再 mouse_click 目标点（右键） |
| 建造建筑 | 左键点侧栏建筑图标 → 等冷却 → 再左键点图标 → 左键点地图放置点 |
| 生产单位 | 左键点侧栏单位图标 |
| 取消冷却/退款 | 右键点侧栏冷却条 |
| 查看地图 | mouse_click 小地图区域，或 wheel 缩放主视口 |
| 放置位置调整 | 空点右键取消放置状态 |
